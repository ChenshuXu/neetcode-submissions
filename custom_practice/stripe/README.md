# Stripe Custom Practice

All Stripe exercises and the OA coverage map live in this folder.

```text
stripe/
├── accept_language_parser/
├── credit_card_validation/
├── datacenter_request_routing/
├── join_two_datasets/
├── linked_merchant_clustering/
├── merchant_fraud_score/
├── merchant_fraud_thresholds/
├── oa_question_map/
├── payment_reconciliation/
└── websocket_load_balancer/
```

The `oa_question_map/README.md` file is the index that maps reported Stripe families to these runnable
packs and to related LeetCode problems.

Run any exercise from the repository root, for example:

```bash
python3 custom_practice/stripe/join_two_datasets/run_tests.py
python3 custom_practice/stripe/datacenter_request_routing/run_tests.py
```
